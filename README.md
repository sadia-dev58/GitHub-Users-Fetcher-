# GitHub Users API Fetcher 🌐

A simple web development project that fetches GitHub users' data using the GitHub REST API and dynamically displays their IDs and profile pictures in an HTML table.

This project demonstrates how to work with APIs using JavaScript's Fetch API and DOM manipulation without using AI tools.

## ✨ Features

- Fetch GitHub users' data from a public API.
- Display user IDs dynamically.
- Display GitHub profile pictures.
- Use JavaScript DOM manipulation.
- Simple and clean table-based layout.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub REST API
- Fetch API

## ⚙️ How to Run

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. The application fetches GitHub users' data and displays it in a table.

## 📚 Concepts Practiced

- API Integration
- Fetch API

- JSON Data Handling
- DOM Manipulation
- querySelectorAll()
